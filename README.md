# gmail-mcp

MCP server exposing one Gmail account + its Google Calendar over HTTP. See `goal.md`.

## Quick start
1. Google Cloud Console setup (see `goal.md` -> Human-only steps)
2. `npm install`
3. `npm run auth` (opens browser once)
4. `docker compose up` -> `http://localhost:3333/mcp`
